# Match execution: record a match afterwards when it wasn't run live (#4061)

A match whose date has passed and that was never started live can now be recorded afterwards. The activity header offers **Record match afterwards** on such a match, planned or completed, and the match-execution screen shows the same button where the dead "Available on match day" line used to be. It opens the match straight in the post-match review with editing on, without running the clock, so the substitutions, goals and minutes go in through the existing late goal / substitution panels, each at its own half and minute, and Finalize locks it as usual. The line-up still comes from match prep only: without a starting line-up the action goes to match prep first. The new `POST /match-execution/{activity_id}/record-afterwards` route refuses today, future dates, a match already started or recorded, and a match with no line-up; each use is written to the audit log. Match day itself is unchanged.
