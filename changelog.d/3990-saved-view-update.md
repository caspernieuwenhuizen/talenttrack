# Saved views: update an existing view with the current filters (#3990)

A saved view can now be updated. Open a saved view, change a filter (on the player report: a section, the order or the layout), and the saved-views menu's first action is **Update "‹name›"**, which stores the current filters on that view and keeps its name and default flag. A view's apply link now carries which view was opened (`sv`), and the filter bar, the player report panel and the team monthly report panel keep it while you change filters. Saving under the name of a view you already have on the screen now offers to replace that view's filters instead of refusing. The Edit dialog keeps rename, default and delete, and loses its "replace its filters" checkbox. It also opens with the view's current name again, which it had stopped doing when the menu moved into the filter bar. This applies to every screen with saved views; a read-only phone screen still shows no write actions.
