# Goals list on a phone: the goal title is text, the row opens the goal (#4241)

On a phone each row of the goals list showed the goal title as a link 18px
high inside a row that is already a link to the same goal. Below 768px the
title now reads as plain text and a tap on it opens the goal through the
row, the same treatment the people list gives the e-mail address. From
768px up the title is a link as before. The list's data is unchanged.
