# Help link: 48px on a phone and a visible keyboard focus ring (#4710)

The shared "Help for this step" link, shown on wizard steps and other screens, was 36px high on a phone, under the 48px minimum for a finger. It now reads the shared tap-target token under a touch screen, while a mouse keeps the compact desktop size. Its focus style also removed the browser's outline, which left keyboard users with only a border colour change. Reaching it with Tab now shows a 2px ring in the primary colour.
