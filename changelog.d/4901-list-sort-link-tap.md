# Lists: the column sort links are full-size tap targets on a touch screen (#4901)

On a tablet, and on a phone while the keyboard has the list's header row on
screen, the links that sort a list by a column were only as big as their text,
a few pixels tall. Under a finger each one is now at least 48 by 48 pixels,
like every other tap target. With a mouse the header row is unchanged.
