# Reports ask for a period before the current season has started (#4637)

When the season marked current had not started yet, every report's default window ran backwards, from the season's future start to today. The player report stopped with a fatal error and its PDF export answered 500, and the other season-scoped reports came back empty. Now there is no default until the season starts. Reports show "Pick a period to see this report" under their filter bar until a pill or a date range is picked. The PDF exports and the report REST reads without a window answer 422 `no_period` with the same message. A typed window whose start is after its end shows a form error instead of a report. A scheduled player report that relies on the season default is skipped for that run, without stopping the schedule. Once the current season has started, the default is the season so far again, as before.
