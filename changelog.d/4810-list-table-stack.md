# Lists on a phone: the same cards, now read as a table (#4810)

The lists built on the shared list table, such as players, teams, PDP
conversations and the CSV import preview, move onto the shared stacked-table
layout. On a phone they look the same: one card per row. A screen reader now
hears each list as a table with its column headers, and the sort links in the
header row show while one of them has the keyboard focus. Media retention now
names each value on a phone (media, player, left), where it showed only the
values before. An empty cell in the CSV import preview no longer takes a line
with a label and nothing next to it.
