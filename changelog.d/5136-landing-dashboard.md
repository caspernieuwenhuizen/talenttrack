# The landing dashboard follows the selected theme (#5136)

Under a visual theme, the landing dashboard, the first screen everyone sees,
still showed the default theme's surfaces, accent and status colours. It now
takes the chosen theme's. On the default theme nothing changes, and colours an
academy set for the dashboard in the visual design-system editor keep
applying there; under a theme, the theme supplies the dashboard's colours, as
it already does for the rest of the product.
