# Report Studio: average per main category and progress over the last five evaluations blocks (#4572)

Bump: minor

The Report Studio gets its evaluation blocks. Average per main category follows the academy's methodology. For a team it reads the team monthly report's evaluations section: each main category's squad average, its change against the period before and the spread of the players' averages, with the squad rating under it. For a player it reads the player report's ratings. It shows scores only, never a coach's written notes, so a family or a scout may see a player's own averages. Progress over the last five evaluations shows a player's latest evaluations per main category, as the progress and radar report reads them, with a dash for a category that was not rated. It is for staff only. Tests hold both blocks to the reports they come from.
