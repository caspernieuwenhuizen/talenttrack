# Report Studio: two first publishes at once answer 409, not 500 (#4641)

When two builders published the same report for the first time at the same moment, one of them could get "The report could not be saved" (500) instead of "Someone published this report at the same moment. Try again." (409). With no versions yet, both version inserts hold only gap locks and can deadlock. Publishing now treats a deadlock or a lock wait timeout on the version insert the same as a taken version number: it rolls back, tries once more, then answers 409. No data was ever written wrongly; only the answer was wrong. Other database errors still answer 500.
