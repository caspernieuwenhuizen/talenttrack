# Planned attendance shows staff the match-day squad the coach picked in match prep (#4260)

`GET /activities/{id}/planned-attendance` answered from the plan made when the match was created, so a player the coach had left out of the squad in match prep still came back as expected and the team manager arranging kit and transport worked from a different squad. Each planned row now carries a read-only `match_squad` (`start`, `bench` or `out`; `null` when there is no match prep or the prep has no row for the player) beside `plan_status`, which keeps the coach's original plan. Only staff for the player receive it; a parent or player gets `null`, because match prep saves while the coach is still composing. The status or reason the coach chose in match prep is never shared, since that can name a medical cause.
