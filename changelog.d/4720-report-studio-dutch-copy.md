# Report Studio: plainer Dutch in the start wizard (#4720)

The start wizard's Dutch now reads as a person would say it. The choice for a report about yourself is "Mezelf", a report that follows the viewer "volgt wie het opent", the period question is "Over welke periode gaat het?", and the team picker says "Kies een team" (that picker label is shared, so the injury, suspension, goal and comparison pickers say "team" too). Separately, the publish confirm in the Report Studio now shows only the count for the roles ticked last, when several counts are on their way at once.
