# Design tokens and themes work with the custom CSS module switched off (#4772)

TalentTrack's colours, spacing and theme settings hang off a `tt-root` class. That class used to come from the custom CSS module, so an academy that switched the module off, or ran a WordPress theme that leaves out the standard body classes, lost every design token at once. Text could then turn dark on the dark header band, among other things. The dashboard now renders its own `tt-root` wrapper, and the body class is added by core. The tokens and the chosen theme apply whatever the module or the WordPress theme does. Installs with the module on see no change. Custom CSS that overrides a token should target `.tt-root`, not `body.tt-root`; the starter templates and the visual editor already do.
