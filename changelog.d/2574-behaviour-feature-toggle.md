Behaviour rating can now be switched off per academy, from the feature toggles screen. Academies that don't score behaviour no longer see the capture button on every player, the bulk action on every team, or the extra step in the evaluation wizard. It is on by default, so nothing changes unless you turn it off, and behaviour already recorded is kept — switch it back on and it is all still there. Setting a player's potential band is unaffected either way.
