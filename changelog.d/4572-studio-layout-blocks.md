# Report Studio: letterhead, key figures, heading, text and page break blocks (#4572)

Bump: minor

The Report Studio gets its layout and text blocks. The letterhead names the team or the player and the period in the club colours, read through the same composers as the team monthly report and the player report. Key figures show the monthly report's headline figures with the change against the period before, for a team and for staff only. A heading and a text block let a builder write about the report itself, in plain text; a note about a player still belongs on a snapshot. A page break starts a new A4 page and is offered only for a report laid out in rows. Tests hold each block's figures to the reports they come from.
