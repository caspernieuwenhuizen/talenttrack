# Minutes report: a half-time substitute is no longer counted as a start (#4059)

The minutes report counted a player as having started when they appeared in
the line-up of either half, so a player who came on at the break got a
starting place: five eleven-a-side games could show 69 starts. Starts are now
read from the same timeline match execution uses to work out each player's
minutes — the half line-ups together with the substitution log — and a start
means on the pitch at kick-off. A match played in quarters is read period by
period. For a match with no match-execution record, the first-half line-up
counts as the starts. The team minutes report, the team statistics tab, the
monthly team report and the player report all read the corrected figure.
