# Training run explains the player notes sheet before attendance is taken (#3671)

The sideline view of a training no longer hides "Notes on players" until someone is on the register. Before attendance is taken it now shows the heading, a line saying notes open up once attendance is taken, and a "Take attendance" button to this training's register (or to the training itself when the register grid is off). The overview before you start the training also names every block, in a list under the timeline strip and as a label on each segment, so a coach can tell which segment is the rondo.
