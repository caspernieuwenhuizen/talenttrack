# Minutes reports: "Matches played" opens the matches it counts (#4507)

On Minutes share, **Matches played** now opens the activities list with exactly the matches it counted: the report's own window, every match type including tournament days, by the same "played" rule the report uses, with past matches expanded. The list's **Showing only:** strip names the count and the window, for example "12 played matches, 17-08-2026 – 30-06-2027". The Minutes distribution report's matches tile opens the same list and shows its played count, and Minutes share links to the distribution report with its window kept. A date drill into the activities list now lands with past activities expanded; **Hide** still folds them away. `GET /activities` accepts `filter[played]=1` for the same list.
