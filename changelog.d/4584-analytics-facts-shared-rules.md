# Analytics: Evaluation coverage reads the activity date; attendance KPIs count the rows the reports count (#4584)

The Evaluation coverage fact read `tt_activities.start_at`, a column that does not exist, so the Evaluation coverage KPI and its explorer showed nothing. It now reads `session_date`. The attendance fact's Present, Absent and Attendance % measures counted rows the attendance reports leave out: trashed or archived activities, activities that were not completed or lie in the future, and players no longer on that team's roster. One shared clause, `AttendanceFlagService::countableRowClause()`, now carries those rules for both the attendance reports and the measures, so the KPI and the report beside it give the same figure. The explorer's row list still shows every attendance row. Saved explorations on attendance may show a different (correct) percentage.
