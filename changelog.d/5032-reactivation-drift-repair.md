# Installs a re-activation reshaped get their migrated tables back (#5032)

Migration 0329 repairs three table shapes that an earlier re-activation or "Retry migrations now" could have put back. Attendance drops the old `session_id` column and its index, so an attendance write no longer fails under strict SQL mode, and guest rows can be saved again. Evaluations move any result left in the old `match_result` column into an empty `game_result` and drop the old column. Players without an account hold NULL again, so a second trial-to-player promotion in a club is not refused. Every step reads the live table first, so an install that never drifted is left as it is.
