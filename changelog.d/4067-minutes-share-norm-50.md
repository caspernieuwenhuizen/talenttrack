# The minutes-share norm defaults to 50% (#4067)

With no target saved under Configuration → Match minutes, every report now draws the minutes-share line and flags players below it at 50% of the available minutes, where it used to be 30%. That covers the team monthly report and its PDF, the Minutes share report and the player report's talking points, and Configuration → Match minutes shows 50 as the default. An academy that has saved its own target keeps it.
