# Visual editor writes only the tokens an academy changed (#4839)

Saving the visual editor no longer writes every field as a site-wide override. A value left at its default is skipped. That includes the default the field had before this release, and the check ignores letter case and `#fff` vs `#ffffff`. An academy that once saved the editor without changing a colour no longer carries borders, muted text, status colours, radii, shadows and heading sizes it never chose. Under a club theme, buttons now follow the theme's primary colour instead of the default green. The editor's defaults now match the plugin's own design tokens: success `#2f9e5e`, warning `#e8902b`, danger `#d8453b`, info `#2d6fb3`, lines `#e3e1d8`, muted text `#6a6d66`, medium corners 6px, large corners 10px, small shadow none, heading 1 1.75rem. Values an academy did change are written as before.
