# Spond: a late kick-off's default end runs past midnight (#4529)

A Spond match that arrives without an end time gets kick-off + 105 minutes, as before, but a late kick-off no longer stops at 23:59: a 22:30 match now ends at 00:15, read as the next day, and lasts the full 105 minutes. The planner PDF and the weekly planner print also show a duration for an activity that ends at exactly midnight (23:00 to 00:00 is an hour), where they used to show none.
