# The player's Activities tab counts an activity as completed by its status (#4990)

The Activities tab on a player's profile, and the number on the tab, now decide what is completed by the activity's own status, as the activity's page and the reports do. An activity that had never been through the planner could show on the tab as completed while its page said it was still planned; it no longer shows until its status is Completed. An activity whose status is Completed but whose planning state was never moved on now does show. So the number on the tab can change for some players. "Today" is the academy's date, so an activity completed today counts from the start of the club's day.
