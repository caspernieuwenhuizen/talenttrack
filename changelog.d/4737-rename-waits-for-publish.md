# Report Studio: a rename waits for publish (#4737)

Renaming a published Report Studio report no longer reaches its readers straight away. The builder renames their draft, and the people the report is published for keep seeing the name of the version they read until the next publish, which copies the new name onto the version and the report. The canvas and the builder's list show the draft name, marked "Changed since publish" while it differs. A report that was never published has no readers, so its name changes at once. Restoring a version also brings back that version's name. Over REST, `name` is the published name; an editor also gets `draft.name` and `draft.name_changed`, and each version has a `name`. Migration 0311 adds a name to every draft and version and fills it from the report's current name.
