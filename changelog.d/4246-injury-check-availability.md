# Injuries: an overdue or incomplete record asks for a check instead of contradicting planning (#4246, #4269)

An injury whose expected return has passed without a recorded return, or that has been open for 14 days without an expected return, no longer gives two answers on two screens. The player's Injuries tab and the squad overview flag it (**Overdue**, or the new **Incomplete**); planned attendance, the match preparation and the tournament wizard's squad step show the player as available with a neutral **Check availability** marker, never a cause. Over the API the marker is a separate boolean, `availability_check`, on `GET activities/{id}/planned-attendance` and `GET match-prep/{id}`; `availability` keeps its two values. The number of days is per academy (`injury_incomplete_after_days`, default 14). The injury recovery reminder now arrives on the day the record needs a decision, goes to the team's physio and head coach (the head coach alone without a physio), moves when the expected return moves and is retired when the return is recorded. A daily sweep on the workflow tick catches records whose date arrives without an edit. An injury with no expected return that is younger than the threshold still marks the player Unavailable, as before; one older than it no longer does.
