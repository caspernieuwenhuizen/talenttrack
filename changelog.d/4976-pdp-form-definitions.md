# PDP conversation forms: the forms as data, and a setting to switch them on (#4976)

Bump: minor

An academy can now pick a set of PDP conversation forms under Configuration → PDP conversation forms. The first set is JG4IT Elite: an outfield and a goalkeeper form, each with 17 items in four sections, scored 1 to 5, word for word from the academy's own forms. Picking the set prepares an evaluation sub-category per item, under the four existing main categories, and an evaluation type per form, so the trainer's scores will show in the radar, the history and the reports. The ordinary evaluation forms never offer these items or types. Forms stay off at every academy until one is picked, and picking is refused, with nothing changed, when the rating scale does not have five steps or a main category is missing. The conversation screens that use the forms follow in the next releases.
