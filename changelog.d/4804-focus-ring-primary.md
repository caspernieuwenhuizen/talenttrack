# The keyboard focus ring follows the primary colour and is easier to see (#4804)

The ring that shows which form field has keyboard focus was a faint fixed green on every design, too pale to see clearly against the page. It is now a solid ring in the academy's primary colour: the Branding primary on the default design, and the theme's primary under Leon Hutten or federation. If a Branding primary is too light to stand out against the page, the ring uses a darker shade of the same colour, so it always reaches at least a 3 to 1 contrast.
