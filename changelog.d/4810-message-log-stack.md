# Message log on a phone: a message's outcome and notes stay readable (#4810)

On a phone each message in the message log is a card with one line per
column. When a line held several parts, such as an outcome with its hint or a
note that nobody in the family can be reached, the parts sat side by side and
the last one ran off the edge of the card. They now stack under each other, as
they do in the table on a larger screen. The message log also moves onto the
shared stacked-table layout, so a screen reader hears it as a table with its
column headers.
