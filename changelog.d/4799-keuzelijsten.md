# Dutch: one word for the lookups area, Keuzelijsten (#4799)

The Dutch interface named the same area two ways: the navigation said "Keuzelijsten", while the Configuratie screens said "Lookuplijsten" and in places "Lookups". It is now "Keuzelijsten" everywhere: the Configuratie tile and crumb, the wp-admin configuration group, the module and backup descriptions, the football-form hint and the canonical-language review tile. The Dutch help topics use the same word. Technical names keep their English form, such as the `_Lookups` sheet of the Excel template.
