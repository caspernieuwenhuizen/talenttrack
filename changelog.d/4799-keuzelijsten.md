# Dutch: one word for the lookups area, Keuzelijsten (#4799)

The Dutch interface named the same area three ways: the navigation said "Keuzelijsten", the Configuratie screens said "Lookuplijsten" or "Lookups", and the setup wizard said "Opzoeklijsten". It is now "Keuzelijsten" everywhere, with "keuzelijstwaarde" for a single value. That covers the Configuratie tile, crumb and editor labels, the wp-admin configuration group, the module and backup descriptions, the setup hint for age groups, the football-form hint, the canonical-language review and its counts, the seed review, the data browser descriptions and the error messages for saving a value. The Dutch help topics use the same words. Technical names keep their English form, such as the `_Lookups` sheet of the Excel template.
