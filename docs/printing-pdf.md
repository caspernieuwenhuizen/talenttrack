# Printing and PDFs

TalentTrack can produce clean, print-ready views of player reports — useful for parent meetings, evaluation handouts or paper records.

## What you can print

Pages with a print icon in the top right:

- **Player rate cards** — the full card, radar and trend.
- **Evaluation detail** — one evaluation with all categories and notes.

The print icon only appears when you can open the report. That means the player themselves, their parents and the staff who can see the player. A parent doesn't see it if the player has hidden their evaluations from parents, because the report is built from them.

## Whose records a print sheet covers

Hiding the icon is not the whole answer, because a print sheet has its own web address and an address can be edited by hand. So every sheet that is about one record asks, before it builds anything, whether you work with that record: the match plan and the match-day team sheet ask about the activity's team, the match analysis about the same, the weekly planner and the training-plan sheet about the team, and the season goals intake about the player — and, for a whole-squad batch, about the squad and then each player in it.

When the answer is no, the sheet prints exactly what it prints for a record that does not exist: an empty sheet, or "not found". That is deliberate. Saying "you may not see this one" would confirm the record is there, and a print address with a number in it should not be a way to find out who is on the academy's books. A squad batch quietly leaves out any player you may not read and prints the rest, with the page count reflecting what you actually got.

A training plan with no team is a club-wide template, so it stays open to everyone who plans training.

## How to print

Click the print icon. A clean version of the page opens in a new window with no menus or sidebars, and the browser's print dialog pops up.

## How to save as a PDF

In the print dialog, choose **Save as PDF** as the destination. Every modern browser supports this.

Tips:

- Set page size to A4 (or Letter in the US).
- Set margins to **Default** or **Normal**.
- Landscape works better for rate cards because the radar and trend charts have more room.

When you're done, close the print window. Your main TalentTrack tab stays exactly where it was.

## Branding

The print layout uses your academy's primary colour and logo. If a printout looks plain, ask an admin to set the academy logo and primary colour in **Configuration → Branding**.
